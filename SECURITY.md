# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions of Netra:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Netra, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. **Email** the maintainer: **Abhinav Singh** <abhinavas430@gmail.com> with:
   - A description of the vulnerability
   - Steps to reproduce
   - Possible impact
   - Any suggested fix (optional)

We will acknowledge your report and work on a fix. After a fix is released, we may credit you in the release notes (unless you prefer to remain anonymous).

Thank you for helping keep Netra and its users safe.
